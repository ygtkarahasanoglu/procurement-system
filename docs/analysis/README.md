# Analysis Archive

This directory holds archived, deep-dive architecture analyses that
informed (but did not themselves ratify) decisions in
`docs/decisions/`. Analysis documents are historical/analytical records —
they establish RATIFIED/DERIVED/OPEN/NOT ANALYZED classifications at the
time they were written, but they do not themselves constitute ratification.

Current archives:

- `D-5-cancellation/` — the cancellation-lifecycle-reversibility analysis
  series (D-5 through D-5.6), the source of the still-OPEN D-5 decision in
  `docs/decisions/open.md`.
